# Macro charts

Interactive Plotly pages for the Kondratiev-wave macro panel.

The [chart index](https://acken2.github.io/macro-charts/) is the usual entry point. Each file is several megabytes and self-contained, so the first load can take a while.

This repository is a latest-only snapshot of those HTML files. It is not a trading system or investment advice.

The written briefings for the latest scored month are [kwave-status.md](kwave-status.md) and [cycle-status.md](cycle-status.md).
